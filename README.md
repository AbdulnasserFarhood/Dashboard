# مساحتي — لوحة الإنتاجية الشخصية

تطبيق ويب شخصي بسيط للمهام، الملاحظات اللاصقة، والاقتباسات التحفيزية.
لا يحتاج خادماً أو تثبيتاً — كل شيء HTML/CSS/JS عادي، والبيانات تُحفظ محلياً
في متصفحك (`localStorage`) على هذا الجهاز فقط.

## التشغيل

**الطريقة الأسرع:** افتح `index.html` مباشرة بالمتصفح (نقرتين عليه).

**أو عبر خادم محلي بسيط** (أفضل إن واجهت أي قيود على فتح الملفات مباشرة،
خصوصاً على بعض إصدارات Chrome):

```bash
# من داخل مجلد المشروع
python3 -m http.server 8000
# ثم افتح http://localhost:8000 في المتصفح
```

أو بواسطة Node:
```bash
npx serve .
```

## هيكل الملفات

```
workspace/
├── index.html     ← الصفحة الرئيسية وبنية الواجهة
├── style.css      ← المتغيرات اللونية + التخطيط العام + المهام
├── notes.css      ← تنسيق لوحة الملاحظات اللاصقة
├── quotes.js       ← مجموعة الاقتباسات التحفيزية المحلية (عدّلها بحرية)
├── app.js         ← منطق المظهر، الترحيب، الاقتباس اليومي، والمهام
├── notes.js       ← منطق الملاحظات: إضافة/تعديل/حذف/تثبيت/سحب/انتهاء تلقائي
└── README.md      ← هذا الملف
```

لا تبعيات خارجية سوى خط Tajawal من Google Fonts (عبر رابط CDN في `index.html`).

## أبرز الميزات

- **المهام:** إضافة سريعة بضغطة Enter، أولوية (عالية/متوسطة/منخفضة)،
  صندوق اختيار للإتمام، تعديل وحذف، شريط تقدّم يومي، وحفظ تلقائي.
- **الملاحظات اللاصقة:** إنشاء/تعديل/حذف، 5 ألوان باستيل، تثبيت الملاحظات
  المهمة، سحب وإفلات لإعادة الترتيب، وحجم البطاقات يصغر تلقائياً كلما
  زاد عددها (شبكة متجاوبة). كل ملاحظة تنتهي وتُحذف تلقائياً بعد 7 أيام
  من إنشائها، مع عرض الوقت المتبقي على كل بطاقة.
- **الاقتباسات:** اقتباس يومي يتغيّر تلقائياً كل يوم، وزر "اقتباس آخر"
  لعرض اقتباس عشوائي فوراً. المجموعة محلية بالكامل (داخل `quotes.js`)
  وأصلية الصياغة — أضف أو عدّل الأسطر كما تحب.
- **المظهر:** فاتح/داكن مع تبديل فوري وحفظ التفضيل، ويتبع تفضيل النظام
  تلقائياً عند أول زيارة.
- **تصميم متجاوب** يعمل على الجوال والتابلت وسطح المكتب، وواجهة عربية
  بالكامل مع دعم RTL صحيح.

## التخصيص السريع

- **الألوان:** غيّر متغيرات `:root` و `[data-theme="dark"]` في أعلى `style.css`.
- **ألوان الملاحظات:** عدّل `--note-yellow / pink / green / blue / peach`
  في `style.css`، وأسماءها في مصفوفة `COLORS` داخل `notes.js`.
- **مدة بقاء الملاحظة:** غيّر `TTL_MS` في `notes.js` (القيمة الحالية 7 أيام).
- **الاقتباسات:** أضف/احذف أسطراً من مصفوفة `QUOTES` في `quotes.js`.

## ملاحظة حول الإصدار السابق

تم استبدال نسخة لوحة المهام الجماعية (قراءة من Google Sheet عبر Apps
Script لمتابعة فريق محدد) بمساحة عمل شخصية بالكامل تعمل من دون أي خادم
خارجي، لأن ذلك هو ما طلبه المواصفات الجديدة (أداة إنتاجية شخصية وليست
لوحة متابعة فريق). إن كنت ما زلت بحاجة للوحة الفريق القديمة التي تقرأ
من Google Sheets، يمكن إبقاؤها كصفحة منفصلة بسهولة.
